# ZYVORAX Termux Tools

A responsive static website for Termux commands, tools and beginner-friendly guides. The layout takes inspiration from the supplied reference image's compact category navigation and clean tool cards, with original ZYVORAX branding.

## Features
- Responsive desktop and mobile layout
- Category filters and live search
- Copy-to-clipboard command buttons
- Featured starter guide and command cards
- No build step or external dependencies

## Run locally
Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**, then save.
4. Wait for the deployment. GitHub will show the published URL in Pages settings.

Review commands before running them. Only test networks and systems you own or have permission to assess.
